A · 静纸（推荐）

一句话
把新的搜索入口接进现有纸面语言里，改动最小、最像"本来就应该长这样"。
字体
中性 grotesque 系统栈（Segoe UI Variable Text），零下载。
色彩
沿用 #FEFEFE 近白底，只有搜索栏是半透明白浮层，其余靠 1px 细线与留白。
记忆点
聚焦时胶囊下方一条 1px 墨线自左向右生长，像画了一条基线。
适用
想要"无感升级"，不希望新标签页气质改变。

B · 暗房

一句话
把新标签页变成一间暗房：只有画亮着，控件退到不打扰的位置。
字体
展示体无衬线 + 小号大写字距微标签，中文走系统栈。
色彩
暖黑底（非纯黑），插画 100% 不透明度，只有搜索栏一处磨砂浮层。
记忆点
纯看模式下鼠标静止 2 秒，全部 UI 淡出，只剩画面。
适用
把新标签页当"看画的地方"，愿意接受从亮到暗的气质变化。

C · 刊头

一句话
把新标签页当一份每日画报来排版，有刊名、有署名、有编辑感。
字体
衬线（Georgia / 宋体栈），四个方向里唯一的衬线方向。
色彩
暖白纸色 #FBF9F5，不用纯白，靠粗细分隔线建立层级。
记忆点
聚焦时输入行右端浮出「⏎ 搜索 pixiv ↗」的极小字提示。
适用
喜欢阅读感与秩序感，不介意图片下方多一行署名文字。

D · 台面

一句话
像一件专业工具：所有信息等宽对齐，搜索是一条命令，动效几乎瞬时。
字体
等宽（Cascadia Mono / Consolas），数字全部 tabular。
色彩
冷灰 #F4F5F7 + 冷灰细线，克制到近乎朴素。
记忆点
聚焦时提示符 `:` 变成实心方块，输入即命令。
适用
想要高信息密度与键盘感，把新标签页当工作台的人。

也可以只取某个细节混搭：比如「A 的配色 + B 的滚动隐去 + D 的键盘提示」，在确认弹层的建议框里写一句即可。
