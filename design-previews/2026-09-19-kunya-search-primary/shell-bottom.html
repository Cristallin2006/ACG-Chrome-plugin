A · Spotlight 升起（推荐）

一句话
静止时胶囊退守底部，图墙是唯一主角；聚焦瞬间胶囊升到视口 38%、暖色暗场压下，搜索夺权。
材质
烟熏玻璃胶囊 + 琥珀焦点环 + 暖调径向 scrim；暗场只压画，不压字。
记忆点
「升起 + 暗场」的一气呵成——Apple Spotlight 式的夺权动画。
代价
多一组位移动画与 scrim 状态机；静止截图看不出它的好，必须看动起来的样子。

B · 中央舞台常驻

一句话
搜索永久钉在画面中央偏上，加大加重，是打开新标签页的第一眼。
材质
更厚的烟熏玻璃 + 常驻琥珀描边环 + 键盘提示 chips；图墙保持原亮度。
记忆点
第一眼就是搜索——最直白的「以搜索为主」。
代价
永久遮挡拼图墙正中心，「一眼是画」的现有契约被削弱，DESIGN.md §0 需改写。

C · 底部加冕舞台

一句话
胶囊不离开底部安全带，底部暗渐变把它托成舞台，上方补微标签与键盘提示。
材质
底部暖黑渐变 + 加宽加高的胶囊 + 微标签 / kbd chips。
记忆点
底边的一条「剧场沿」——画廊与搜索区的分割线。
代价
提升最保守：搜索仍不在视线中心，只是更重要的配角。

D · 顶部命令栏

一句话
搜索变成顶置全宽命令栏：直角化、等宽字体、kbd 提示，像浏览器 UI 的一部分。
材质
直角命令栏 + 等宽 kbd chips + 更密的排版；唯一的圆角留给开关。
记忆点
工具感——新标签页即工作台，搜索是一条命令。
代价
效率工具气质与暗房画廊的观赏气质有张力，画面「性格」会变。

也可以只取某个细节混搭：比如「A 的升起 + C 的底部舞台渐变」「D 的等宽 kbd 提示加到 A 上」，在确认弹层的建议框里写一句即可。
