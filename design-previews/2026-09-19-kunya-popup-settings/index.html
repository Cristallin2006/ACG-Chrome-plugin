A · 暗房延伸(推荐)

一句话
沿用主页面的暗房 token:暖黑底、烟熏玻璃卡片、琥珀只给开态与焦点——popup 是画廊的调光台。
材质
rgba(19,17,16) 面板 + 琥珀 #e0a45e;分组卡片带「片夹缺口」;登录状态一枚琥珀呼吸点。
记忆点
底片片夹式分组——设置页第一次看起来像这个产品自己的东西。
代价
保守:它是「正确的默认」,惊喜感不如 C/D;深色 popup 在白底浏览器工具栏下对比强。

B · 分类工作台

一句话
左侧分类导航(内容源 / 过滤 / 账户)+ 右栏内容,设置按任务归类而不是一列到底。
材质
偏冷的蓝灰 + 琥珀选中竖条;Linear / macOS 设置式密度。
记忆点
左栏琥珀竖条——一眼知道自己在改哪类东西。
代价
400px 宽塞双栏,每栏都变窄;导航在 10 个区块的规模下略重。

C · 印刷目录

一句话
浅暖纸面 + 深墨字 + Georgia 衬线大编号,控件做成表单线——popup 像展览图录的清单页。
材质
纸色 #f5f1ea + 墨 #241f1a + 印刷琥珀 #b4762e;唯一的亮色方向。
记忆点
衬线 01–10 大编号目录节奏,设置页有了「出版物」的气质。
代价
与暗房主界面是两种气质(这可以是优点也可以是断裂);实现时要小心与主页面 token 的关系。

D · 控制台

一句话
等宽字体 + 1px 分隔线 + [x]/[ ] 记号,设置即一份可读的配置文件。
材质
暗底 + 等宽栈 + 字符状态记号;无圆角、无投影、无卡片。
记忆点
`# source mode` 注释行区块标题——terminal 用户会会心一笑。
代价
等宽 + 中文混排天然局促;对非技术用户最不友好,扫读门槛最高。

也可以只取某个细节混搭:比如「A 的暗房材质 + B 的分类导航」「C 的衬线标题用到 A 上」,在确认弹层的建议框里写一句即可。
